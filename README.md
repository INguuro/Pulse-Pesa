# pulse_pesa

Fetches sample customer records from JSONPlaceholder, flattens the requested attributes, writes CSV summaries, and saves a customer distribution chart.

## Run

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python analysis.py
```

Generated files are saved in `output/`. An internet connection is required to retrieve the data.
